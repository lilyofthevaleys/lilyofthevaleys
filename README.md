I like wearing multiple hats — frontend, backend, data pipelines, infrastructure. Most of what I build starts as "I don't know how to do this yet," which is usually the point.

Right now I'm doing technical operations work at Eterna Indonesia while finishing my Information Systems degree, which means I spend about half my time writing application code and the other half keeping things running.
